# RyotaStudioJP Web Portfolio

Static HTML/CSS/JavaScript demo websites for Fiverr and CrowdWorks.

- `/bakery/`: 1-page bakery landing page
- `/salon/`: 3-page salon site
- `/corporate/`: 6-page B2B corporate site

All sample businesses are fictional. Forms are demonstrations and do not transmit data. Google Fonts may require an internet connection.

## Deployment

Cloudflare Pages Git integration: Production branch `main`, Framework preset `None`, build command blank, output directory `/` (repository root). If the UI does not accept `/`, use `.`.

Do not put confidential client work or credentials in this public repository. For client work create separate private repositories and use access-controlled preview deployments.
