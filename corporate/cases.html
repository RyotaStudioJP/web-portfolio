自動車部品

A社（自動車部品メーカー／従業員 約800名）

プレス設備の突発停止を、振動データで事前に検知

導入製品：RV-200 ×64台、RG-10 ×4台、RIKTO VIEW

CHALLENGE / 課題

大型プレス機の主モーターが年に数回突発停止し、そのたびに半日以上ラインが止まっていた。点検は月1回の目視と聴音のみ。

SOLUTION / 対策

主要設備64台に振動センサーを後付け。軸受の振動が平常時から外れた段階で保全担当者に通知する運用に切り替えた。

RESULT / 効果

交換部品を計画的に手配できるようになり、突発停止が大きく減った。点検ルートも見直し、巡回時間を短縮。

-72%突発停止の件数（前年比）
-35%点検の巡回時間
食品

B社（食品メーカー／従業員 約300名）

冷蔵倉庫28室の温度記録を、紙から自動記録へ

導入製品：RT-40 ×56台、RG-10 ×2台、RIKTO VIEW

CHALLENGE / 課題

28室の冷蔵庫を1日3回巡回し、温度を手書きで記録していた。夜間の温度異常に翌朝まで気づけないことがあった。

SOLUTION / 対策

各室に校正証明付きの温湿度ロガーを2台ずつ設置。基準を外れると夜間でも当番者にメールで通知する。

RESULT / 効果

記録作業がなくなり、取引先監査には帳票をそのまま提出。夜間の異常にも即座に対応できるようになった。

月40h記録・点検作業の削減
0件導入後の温度逸脱による廃棄
半導体

C社（電子部品メーカー／従業員 約1,200名）

クリーンルームの差圧・粒子数を一元監視

導入製品：RP-10 ×30台、RT-40 ×40台、RG-10 ×3台

CHALLENGE / 課題

差圧・温湿度・粒子数の計測器がメーカーごとに分かれ、異常に気づくまで最大15分かかっていた。

SOLUTION / 対策

既存の粒子カウンターからもデータを取り込み、1画面で全エリアを監視。ドア開放の検知も追加した。

RESULT / 効果

異常の発生から通知までがほぼ即時になり、歩留まりの低下を早い段階で防げるようになった。

即時異常に気づくまでの時間（従来 最大15分）
+1.8pt歩留まり
化学

D社（化学メーカー／従業員 約600名）

防爆エリアのポンプ監視を、巡回点検から常時監視へ

導入製品：RV-200 ×24台、RG-EX ×2台、RIKTO VIEW

CHALLENGE / 課題

防爆エリアは電気工事の制約が多く、ポンプの状態監視は2人1組の巡回点検に頼っていた。

SOLUTION / 対策

防爆ゲートウェイと電池式センサーで、配線工事を最小限に抑えて24台のポンプを常時監視。

RESULT / 効果

危険エリアへの立ち入り回数が減り、メカニカルシール劣化の兆候を早めにとらえられるようになった。

-60%危険エリアへの立ち入り回数
3件初年度に未然に防げた故障
物流

E社（物流会社／従業員 約450名）

冷凍倉庫の温度記録を、荷主へのレポートに活用

導入製品：RT-40 ×32台、RG-10 ×2台、RIKTO VIEW

CHALLENGE / 課題

荷主から保管温度の証明を求められるたびに、紙の記録をスキャンして送っていた。

SOLUTION / 対策

庫内の温度を自動記録し、荷主ごとに月次の温度レポートを自動作成する仕組みを導入。

RESULT / 効果

レポート作成の手間がなくなり、温度管理の透明性が評価されて新規の荷主獲得にもつながった。

月12hレポート作成時間の削減
2社温度管理を理由に獲得した新規荷主
産業機械

F社（産業機械メーカー／従業員 約250名）

自社製品にセンサーを組み込み、保守サービスを開始

導入製品：RV-200（OEM）、RIKTO VIEW（API連携）

CHALLENGE / 課題

納入した機械の故障は、顧客から連絡を受けて初めて把握していた。保守契約の提案材料も乏しかった。

SOLUTION / 対策

出荷する機械に振動センサーを組み込み、APIで自社の保守ポータルに稼働データを表示。

RESULT / 効果

稼働データにもとづく予防保守プランを有償サービスとして開始。顧客の満足度も向上した。

38%保守契約の加入率（新規納入機）
-45%緊急出動の件数
